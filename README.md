# Zoho CRM Widgets

Custom widgets built for Zoho CRM to enhance CRM workflows, automate business processes, and improve user productivity.

---

## Overview

This repository contains custom widgets developed for Zoho CRM using JavaScript, HTML, CSS, and Zoho CRM APIs.

The widgets are designed to:

- Improve CRM usability
- Automate repetitive tasks
- Provide better visibility into customer and sales data
- Integrate external systems with Zoho CRM
- Enhance business workflows for sales and support teams

---

## Features

- Custom CRM dashboard components
- API integrations with external services
- Real-time CRM data display
- Workflow automation
- Responsive UI components
- Zoho CRM SDK integration
- OAuth/API authentication support

---

## Technologies Used

- JavaScript
- HTML5
- CSS3
- Zoho CRM SDK
- REST APIs
- OAuth 2.0
- JSON
